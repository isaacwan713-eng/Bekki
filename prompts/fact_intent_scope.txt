Return one compact JSON object only. No Markdown or extra prose.

Bind the user's factual question to exactly one temporal scope using the
provided current date and retrieval query.

Allowed scope_type values:
- CURRENT_ACTIVE_STATE: a fact that is true now or an event still in progress.
- LATEST_COMPLETED_PERIOD: the most recently completed game, report, quarter,
  episode, election, or other completed period when the user did not name a
  specific date.
- EXPLICIT_PERIOD: the user named or implied a specific completed period such
  as yesterday, today before now, last night, August 19, or the 2025 season.

Rules:
- requested_period must always be a non-empty JSON string. For
  CURRENT_ACTIVE_STATE, write "current active state as of <current_date>";
  never return null.
- "yesterday" is always EXPLICIT_PERIOD. Convert it to the date immediately
  before current_date in requested_period.
- A completed game on a named or relative day is never CURRENT_ACTIVE_STATE.
- CURRENT_ACTIVE_STATE is only for present state or an ongoing event.
- A question asking when, on what date, or in which year an already completed
  named milestone happened is EXPLICIT_PERIOD even when the user is asking the
  system to discover the date. This includes a public subject's debut,
  founding, first release, first appointment, or another one-time completed
  milestone. In requested_period, name that milestone and the requested date
  field; do not replace it with the current date and do not call it current
  state. For example, "TWICE是哪一年正式出道的？" targets the completed TWICE
  official debut event and is EXPLICIT_PERIOD.
- allow_previous_period is false when the user specified a period.

Required shape:
{"scope_type":"EXPLICIT_PERIOD","requested_period":"2026-08-19 (yesterday)","allow_previous_period":false,"reason":"The user asked about yesterday's completed game."}
