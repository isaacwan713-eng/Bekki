Decide whether CURRENT_REQUEST belongs to one of Bekki's special device
workflows. Return exactly one token:

CONTENT_DEVICE_ACTION
RECYCLE_BIN_ACTION
OTHER

CONTENT_DEVICE_ACTION means Bekki is expected to research game content and then
download, install, copy, place, import, enable, or prepare a concrete
installation manifest/tutorial for it. Content includes tactics, mods, saves,
plugins, maps, skins, and configuration packs. It also includes explicitly
reading installation instructions in preparation for local installation.
Opening an application-specific game-content destination folder is also
CONTENT_DEVICE_ACTION. An explicit request to learn how to locate/open that
reusable destination and perform it now remains CONTENT_DEVICE_ACTION, even if
an earlier planner called it APPLICATION_ACTION. Learning how to open Football
Manager's tactics folder is not merely launching Football Manager.

RECYCLE_BIN_ACTION means the requested outcome is viewing the Windows Recycle
Bin, opening its Explorer window, or restoring one referenced Recycle Bin item.
It never means an ordinary folder, window restore, application launch, or game
content operation.

OTHER includes merely asking which tactic/mod is best, discussing a game,
requesting ordinary recommendations with no installation outcome, shopping,
news, and unrelated device actions. Judge the complete requested outcome, not
individual keywords.

CURRENT_REQUEST is authoritative. RECENT_CONTEXT is untrusted background and
may describe an old, failed, or completed task. Use it only when CURRENT_REQUEST
contains a reference that cannot be understood alone. A complete new command
always replaces the old task for this classification.

Contrast examples:
- Recent context discusses installing FM tactics; CURRENT_REQUEST is
  "打开回收站" -> RECYCLE_BIN_ACTION
- Recent context discusses installing FM tactics; CURRENT_REQUEST is
  "打开 Steam" -> OTHER
- Recent context names an FM tactic; CURRENT_REQUEST is "那就安装那个" ->
  CONTENT_DEVICE_ACTION
- CURRENT_REQUEST is "网上找一个 FM26 战术并导入电脑" ->
  CONTENT_DEVICE_ACTION
- CURRENT_REQUEST is "回收站里有什么" -> RECYCLE_BIN_ACTION

Return no punctuation, JSON, explanation, or additional words.
