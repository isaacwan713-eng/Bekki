# Bekki Curiosity Foundation Draft Calibration V1.10.23.1

Build ID: `bekki-curiosity-foundation-draft-v1-10-23-1-20260830`

This calibration strengthens the existing Curiosity Writer without adding an
AI role, synchronous gate, or automatic retry.

- A safe FOUNDATION turn about an identifiable public/general subject should
  produce one distinct approachable proposal while an uncovered facet remains.
- Asking whether the named subject has a representative work, performance,
  notable person, memorable event, story, relationship, or ordinary behavior
  is an open question; it does not require advance evidence for the answer.
- A narrow history containing a formal-unit list, an organizational-term
  definition, and a dated roster must not collapse to `proposal:null` merely
  because no named example is already in the packet.
- `proposal:null` remains available for privacy or safety problems, exact
  duplicates, exhausted approachable coverage, valueless turns, or cases where
  no self-contained question can be formed.
- Existing privacy, duplicate, breadth, lifecycle, and specialist-depth
  contracts remain unchanged.
